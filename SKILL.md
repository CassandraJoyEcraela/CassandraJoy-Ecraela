# Working Preferences & AI Collaboration Standards

This file documents how I like to work with AI tools (like Claude) on this repository and in my Executive MBA coursework.

## Working Preferences

- Prefer clear, concise communication over jargon — I'm learning Git/GitHub, so plain-language explanations are helpful.
- When editing files, explain *why* a change is being made, not just what changed.
- Favor Markdown formatting that's easy to scan: short paragraphs, headers, and bullet points where appropriate.

## AI Collaboration Standards

- I use AI tools to help draft, edit, and organize my coursework and portfolio content — all substantive decisions and final review are mine.
- Any AI-assisted content should be reviewed by me before committing, and I take responsibility for what's published in this repo.
- Sensitive or confidential information (e.g., real Disney business data beyond what's already public in my resume) should never be added to this repository.
- Commit messages should be written by me or clearly describe AI-assisted changes so my commit history stays an honest audit trail.

## Repository Conventions

- `docs/decisions/` — Dated decision memos, named `YYYY-MM-DD-lastname-topic.md`
- `docs/templates/` — Reusable project templates
- `.claude/skills/` — Reusable AI instruction files for this repo
