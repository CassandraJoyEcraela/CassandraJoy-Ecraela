## How I Want AI to Work With Me

- **Role in drafting:** Drafter — go ahead and produce a full first draft rather than just outlining or asking me to write it. I'll edit from there.
- **Explanation style:** Plain English with definitions. I'm learning Git and technical workflows for the first time, so spell out jargon (e.g., "stage" = "mark a file to be included in the next commit") rather than assuming I already know it.
- **Feedback approach:** Direct. Tell me plainly what's weak or missing rather than softening it — I'd rather fix it than guess.
- **Reusable skills:** Yes — when a task is likely to repeat (reviewing my bio, writing a decision memo, formatting a resume bullet), create a skill file in `.claude/skills/` so future sessions can reuse it.

## Standards for This Repo

- All substantive decisions and final review are mine — AI drafts, I approve.
- Any AI-assisted content (bio, resume, memos) gets a disclosure line: *"Drafted with help from Claude (Anthropic, 2026); reviewed and edited by me."*
- Never commit real Disney business data beyond what's already public in my resume, or any secrets/credentials — see `.gitignore`.
- Meaningful AI sessions (real drafting/decisions, not typo fixes) get a short entry in `prompt-log.md`.
- Settled, reversible decisions about how I work go in `docs/decisions/` as dated memos.
